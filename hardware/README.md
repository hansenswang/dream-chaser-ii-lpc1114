# 硬件设计说明 / Hardware Notes

逐梦贰号控制板 —— 70×100 mm 双层板，立创 EDA 设计，免费打样。本文记录分区设计、供电架构、封装选择与焊接经验。

The 逐梦贰号 controller board — a 70×100 mm two-layer design in JRLCEDA. These notes cover partitioning, power architecture, package choices and what the soldering taught us.

---

## 1. 分区设计 / Functional partitioning

```
┌─────────────────────────────────────────────────────────────────────┐
│  电源区        主控区                      驱动区                    │
│  ┌──────────┐  ┌────────────────────┐      ┌─────────────────────┐  │
│  │ 电池输入  │  │  LPC1114 MAS 核心板 │      │  RZ7899 ×4          │  │
│  │ D1 SW1   │  │  (2×20 排针座)      │      │  每路独立 VCC/GND    │  │
│  │ AMS1117  │  │                    │      │  N20 电机直连        │  │
│  └──────────┘  └────────────────────┘      └─────────────────────┘  │
│                                                                       │
│  传感区                                    交互区                     │
│  ┌──────────┐  ┌────────────────────┐      ┌─────────────────────┐  │
│  │ ITR9909×5│  │  HC-SR04 接口      │      │  LED ×6  K1 蜂鸣器  │  │
│  │ 比较器    │  │  E01-ML01D 无线    │      │  OLED 接口          │  │
│  └──────────┘  └────────────────────┘      └─────────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘
```

**为什么这样分区：** 电机驱动区与传感区在物理上分居板子两端。这不是为了好看 —— 四个 RZ7899 在换向时会在供电上产生电流阶跃，如果驱动区紧邻循迹比较器，跳变会通过地平面耦合进传感器信号，表现为偏差值随机跳动。分居两端后两地之间有明显距离，配合地平面分割，问题基本消失。

> **Why the drivers sit at the far end.** The four RZ7899s produce current steps on commutation. Placing them adjacent to the line-sensor comparators couples those steps into the sensor signals through the ground plane, which shows up as random offset jitter. Separating them physically, with a split ground return, largely removes it.

## 2. 供电架构 / Power architecture

```
   电池 2×14500 串联 (7.4V 标称 / 8.4V 满电)
        │
        ▼
      D1  ── 防反接肖特基
        │
        ▼
      SW1 ── 电源开关
        │
   ┌────┴────────────────────────┐
   │                             │
   ▼                             ▼ (7.4V 直供)
 AMS1117-3.3                    4× RZ7899 + 4× N20
   │
   ├─ C1  100 µF（电解，低频滤波）
   ├─ C3   10 µF（陶瓷，中频）
   └─ C4   10 µF（陶瓷，中频）
   │
   ▼
 3.3V ──► LPC1114 / ITR9909 / OLED / 蜂鸣器 / E01-ML01D

 电源指示： R2 10 kΩ + LED1（常亮，电流极小）
```

**多级滤波的意义：** 100 µF 电解电容的等效串联电感使其对高频无效，10 µF 陶瓷电容则对低频无效。两者并联覆盖不同频段 —— 这是 LDO 数据手册推荐的典型配置，也是本板电源纹波能够满足 ADC 测量要求的原因。

**LDO 压差约束：** AMS1117 典型压差 1.1 V，因此电池电压低于 4.4 V 时 3.3 V 输出将无法维持。两节 14500 在 6 V 附近仍有充足余量，但这也解释了低压监测阈值取 6.6 V 的原因 —— 留出余量而非等到输出开始塌陷才报警。

> **Why the LDO dropout matters.** AMS1117 needs about 1.1 V of headroom. Two 14500 cells hold plenty until around 5 V, which is why the low-battery warning is set at 6.6 V — early enough that the 3.3 V rail never collapses.

## 3. 封装选择 / Package choices

| 器件 | 封装 | 理由 |
|------|------|------|
| RZ7899 | SOP-8 | 唯一需要贴片焊接的器件；驱动电流能力与散热需要 |
| 核心板座 | 2×20 排针，600 mil 间距 | 兼容 LPC1114 / STC32 核心板，便于更换 |
| 电机接口 | 2.54 mm 排针 | 方便单独测试某一路而无需飞线 |
| 其余阻容/三极管 | 插件 | 降低焊接门槛，适合新手；板子空间充足 |

**关于 600 mil 排针间距：** 这是刻意的选择 —— LPC1114 与 STC32G 两种核心板的排针间距不同，采用 600 mil 并配合 2×20 针座可以同时兼容两种核心板。注意 STC32G 工作在 5 V 而 LPC1114 在 3.3 V，更换核心板时必须确认逻辑电平兼容性。

## 4. 焊接经验 / Fabrication notes

**RZ7899 是最容易出问题的器件：** SOP-8 封装引脚间距 1.27 mm，手工焊接时容易出现桥接或虚焊。首次上电时表现为某个轮子不转，用万用表逐个引脚测通断后定位到虚焊，重新补焊后正常。建议的焊接顺序是：先固定对角两个引脚定位，再逐个补焊其余引脚，最后用吸锡带清理桥接。

**电机并联 104 瓷片电容：** 每个 N20 电机两端并联 100 nF 瓷片电容，吸收换向电刷产生的尖峰。这在原设计中被明确提出，实测未加时可以在示波器上看到明显的换向毛刺。

**循迹探头的电位器：** 每个 ITR9909 板上的电位器需要单独调节。在白色地板上调至刚好不触发（输出低），再放到黑线上确认触发（输出高）。五路阈值不一致会导致循迹偏向一侧 —— 这是最容易被忽视的机械校准环节。

## 5. 如果重做 / What I would change

1. **用硬件 PWM 替代软件 PWM 驱动电机** —— 当前软件 PWM 依赖 `Delay_ms()` 阻塞主循环，导致超声波测量、循迹采样之间存在明显的时序耦合。使用硬件 PWM 可以让主循环从延时中解放出来，各任务的时序也随之解耦。
2. **增加地平面完整性** —— 当前双层板的模拟地与数字地未严格分割，ADC 读数中可以观察到与电机状态相关的噪声。
3. **为循迹探头提供独立稳压** —— 探头供电直接取自 3.3 V 主线，电机启动时的压降会影响发射管亮度，进而影响阈值判断。
4. **预留 I²C 与 SPI 的额外从机位** —— 当前 OLED 占用了一条位操作 I²C，无线模块占用了 SPI，若要再增加传感器将需要软件模拟更多总线。
5. **把电平兼容问题前移到选型阶段** —— 3.3 V 主控与 5 V 外设混用是本次设计埋下的一处隐患，应在原理图阶段就用明确的分压或电平转换解决。
